# The Funniest One-Line Resignation Letter

Entry for the make.fun competition "The Funniest One-Line Resignation Letter".

`main.ts` writes a single line to `/output/entry.txt`: the resignation letter
of a cron job that has fired every minute since March and whose entire job
description is one config comment — `temp fix`.

Run it with Node 22+: `node main.ts [optional-output-path]`.
